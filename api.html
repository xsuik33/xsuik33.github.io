Documentación de la API

Esquema de integración y consultas asíncronas para el ecosistema de base de datos distribuidas en Supabase.

1. Inicialización de la Base de Datos

La pasarela asíncrona requiere instanciar el cliente centralizado inyectando las constantes seguras decodificadas de la memoria interna:

const db = window.supabase.createClient(SB_URL, supabaseKey);

2. Extracción de Catálogo Local

Para mapear los registros persistidos en el esquema relacional local sin filtros restrictivos artificiales:

const { data, error } = await db
  .from('libros')
  .select('*');

3. Inserción Automática de Préstamos

Estructura modular requerida para efectuar la solicitud física e insertar las marcas de tiempo calculadas para la devolución a los 7 días naturales:

fechaEsperada.setDate(fechaSalida.getDate() + 7);

await db.from('prestamos').insert([{
  id_usuario: idUsuario,
  id_ejemplar: idEjemplarFisico,
  fecha_salida: fechaSalida.toISOString().split('T')[0],
  fecha_esperada: fechaEsperada.toISOString().split('T')[0]
}]);
