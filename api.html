Documentación de la API

Guía técnica para la integración con el backend de Supabase.

1. Conexión al Cliente

BiblioTech utiliza el cliente oficial de Supabase. Para inicializar la conexión en tu proyecto, usa el siguiente script:

const db = window.supabase.createClient(SB_URL, supabaseKey);

2. Consulta de Catálogo

Para obtener todos los libros registrados en la tabla 'libros':

const { data, error } = await db
  .from('libros')
  .select('*');

3. Lógica de Préstamos

El sistema calcula automáticamente la fecha de entrega sumando 7 días a la fecha actual:

fechaEsperada.setDate(fechaSalida.getDate() + 7);
db.from('prestamos').insert([{...}]);
